# UNID
## Status do Projeto: Finalizado
---
## Contexto
Esse site foi feito sob demanda com um prazo de poucos dias. Foi feito para o sistema de RPG UNID, com o objetivo de suprir as necessidades do mestre e dos players.

---
## O que faz
É a porta de entrada para todos que querem conhecer o sistema, montar fichas e usar como auxilio durante sessões com a possibilidade de analizar a história do universo, 
as raças que existem, vizualiar a ficha do usuario e rolagem de dados.
